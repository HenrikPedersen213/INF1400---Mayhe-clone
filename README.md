# Mayhem Clone (Oblig 3)

A 2-player spaceship combat game built with Pygame. Players control their spaceships, manage fuel, shoot at each other, and land on landing pads to refuel.

## Project Structure

*   `src/`: Contains the Python source code for the game.
    *   `game.py`: The main entry point and game loop.
    *   `config.py`: Game configuration and constants.
    *   `spaceship.py`: Logic for player spaceships.
    *   `bullet.py`: Logic for projectiles.
    *   `obstacles.py`: Environment elements, including obstacles and landing pads.
*   `doc/`: Documentation folder.

## How to Run

Make sure you have Python and Pygame installed:
```bash
pip install pygame
```

To start the game, navigate to the project directory and run `game.py`:
```bash
python src/game.py
```

## Gameplay
- **Objective:** Destroy your opponent's ship to gain points.
- **Fuel:** Manage your fuel carefully. Land on a landing pad to refuel.
- **Hazards:** Avoid crashing into obstacles or colliding with the opponent at high speeds!

## Config
- **HARDMODE** Adjust the config file to remove the standard hardmode
- **Adjust** Make any changes you want for this game, its yours!
