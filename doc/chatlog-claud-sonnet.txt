1. Pause/Step System

2. Draw Hitboxes as Overlays
python

def draw_hitboxes(surface, sprites):
    for sprite in sprites:
        # Rect hitbox
        pygame.draw.rect(surface, (255, 0, 0), sprite.hitbox, 2)

        # Circle hitbox
        pygame.draw.circle(surface, (0, 255, 0), sprite.rect.center, sprite.radius, 2)

        # Draw center point
        pygame.draw.circle(surface, (255, 255, 0), sprite.rect.center, 3)

def draw_debug_text(surface, sprite):
    lines = [

KEYDOWN in Pygame

KEYDOWN is an event that fires once when a key is first pressed (not held).
Basic Usage
python

for event in pygame.event.get():
    if event.type == pygame.KEYDOWN:
        if event.key == pygame.K_SPACE:
            print("Space pressed!")

The Event Object

When KEYDOWN fires, the event has 3 useful attributes:
Attribute	Description	Example
event.key	Key constant (int)	pygame.K_a, pygame.K_LEFT
event.unicode	The character typed	'a', 'A', '!'
event.mod	Modifier keys held	pygame.KMOD_SHIFT
Checking Modifier Keys
python

if event.type == pygame.KEYDOWN:
    if event.key == pygame.K_z:
        if event.mod & pygame.KMOD_CTRL:
            print("Ctrl+Z!")
        elif event.mod & pygame.KMOD_SHIFT:
            print("Shift+Z")

Common mods: KMOD_CTRL, KMOD_SHIFT, KMOD_ALT
KEYDOWN vs get_pressed()

These are not the same thing:
python

# KEYDOWN — fires ONCE on press, good for:
# jumping, shooting, menu navigation, text input
for event in pygame.event.get():
    if event.type == pygame.KEYDOWN:
        if event.key == pygame.K_SPACE:
            player.jump()  # called once per keypress ✅

# get_pressed() — true every frame while held, good for:
# movement, charging, holding a button
keys = pygame.key.get_pressed()
if keys[pygame.K_LEFT]:
    player.x -= 5  # moves smoothly every frame ✅

    Rule of thumb: Use KEYDOWN for one-shot actions, get_pressed() for continuous input.

Text Input

Use event.unicode to capture typed characters (handles shift, caps lock etc.):
python

text = ""

for event in pygame.event.get():
    if event.type == pygame.KEYDOWN:
        if event.key == pygame.K_BACKSPACE:
            text = text[:-1]
        else:
            text += event.unicode  # correctly gives 'A' when shift held
